# Architecture

The client is the `app` package (Expo SDK 57, Expo Router). From the repo root, `pnpm app` starts the Expo dev server.

Feature work is not built yet. Do not infer routes, providers, or data flow from `poc/`. That tree is a proof of concept. Its notes live in `poc/docs/`.

Record request flow and the files that own it here when that work starts. Record a choice that later work must not undo in `docs/decisions/`.
